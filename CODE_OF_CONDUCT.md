# Code of conduct

Sanjeh follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and kind, to learners and to contributors at every
level of English and of programming. Criticise work, not people. Many people
here write English as a second language; read generously and answer plainly.

To report unacceptable behaviour, contact the maintainer privately on GitHub
([@its-saeed](https://github.com/its-saeed)). Reports are kept confidential.
