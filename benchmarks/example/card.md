# Example set — not a benchmark

Twelve lines written for this repository (MIT, as Sanjeh), with **invented**
labels, so that every command in the README and `CONTRIBUTING.md` runs on a
fresh clone. It shows the item format and exercises the tools. Its results
say **nothing** about any model: don't report them, and don't fit on it.

- **Lines**: everyday British and American speech, written for this set; no audio, so no `heard`.
- **Labels**: one made-up rater at B1, both skills (`ear`, `mouth`).
- **Split**: 8 `fit`, 4 `test`.
